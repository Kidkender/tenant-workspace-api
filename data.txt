Schema chi tiết
🏢 tenants
tenants
- id (uuid, pk)
- name
- slug (unique) -- dùng cho subdomain
- plan_id
- owner_user_id
- created_at
- updated_at

👉 đại diện cho “company”

👤 users
users
- id (uuid, pk)
- email (unique)
- password
- name
- created_at
- updated_at

👉 user là global (không thuộc riêng tenant)

🔗 tenant_users (pivot quan trọng nhất)
tenant_users
- id
- tenant_id (fk)
- user_id (fk)
- role_id (fk)
- status (active, invited, removed)
- joined_at

👉 1 user có thể thuộc nhiều tenant

🔐 roles
roles
- id
- name (admin, member)
- description

👉 có thể global hoặc tenant-specific (tuỳ bạn nâng cấp)

🔑 permissions
permissions
- id
- key (create_task, delete_task)
- description
🔗 role_permissions
role_permissions
- role_id
- permission_id
📋 tasks
tasks
- id (uuid)
- tenant_id
- title
- description
- status (todo, doing, done)
- created_by (user_id)
- assigned_to (user_id)
- due_date
- created_at
- updated_at

👉 🔥 MUST có tenant_id

💬 task_comments
task_comments
- id
- task_id
- tenant_id
- user_id
- content
- created_at
📎 attachments (optional)
attachments
- id
- tenant_id
- file_url
- uploaded_by
- created_at
💰 3. Billing (SaaS core)
📦 plans
plans
- id
- name (free, pro, enterprise)
- price_monthly
- price_yearly
- max_users
- features (json)
💳 subscriptions
subscriptions
- id
- tenant_id
- plan_id
- status (active, canceled, trial)
- started_at
- expired_at
⚡ 4. Indexing (rất quan trọng)

👉 Nếu bạn bỏ qua phần này = không production

Ví dụ:
CREATE INDEX idx_tasks_tenant ON tasks(tenant_id);
CREATE INDEX idx_tasks_assigned ON tasks(assigned_to);
CREATE INDEX idx_tenant_users ON tenant_users(tenant_id, user_id);
